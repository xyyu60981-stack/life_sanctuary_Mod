# 植物食品接入

第35条保留烤刺桫椤茎，其食用属性与原版面包一致。PlantFoodProfiles.roastedThornTreeFernStem()直接返回Foods.BREAD，包含营养、饱和、普通食用时长和其他原版食用设置，不新建近似副本，不添加状态效果、加速食用、额外饥饿或其他差异。

内容作者在正式烤刺桫椤茎物品注册时使用new Item.Properties().food(PlantFoodProfiles.roastedThornTreeFernStem())。不要另覆盖该物品的食用时间或效果，否则不再等同面包。当前没有实际刺桫椤茎／烤茎物品，未虚构其ID、掉落或烧制产量／时间；这些随具体物种材料和美术接入。本批提供食物定义，不声称游戏中已能取得、烧制和食用烤茎。

此前第26条田字萍粥继续独立使用marsileaPorridge()，问荆粥也未改变；没有把饥饿效果或问荆孢子茎的10刻食用时间应用到烤茎。

验证：全项目使用本地缓存依赖独立javac通过，未运行Gradle。直接引用原版常量，无需为复制出来的数值写重复测试；未启动游戏或执行实际食用、烧制、动画、多人同步验证。
