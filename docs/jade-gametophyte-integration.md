## 当前实现

LifeSanctuaryJadePlugin 使用 Jade 15.10.5 的官方 WailaPlugin 入口，为 SharedGametophyteBlock 和旧 EquisetumArvenseGametophyteBlock 注册服务端数据与客户端提示。覆盖六类共用配子体及旧问荆兼容方块。

显示真实物种、环境允许生长／暂停／未知／故障状态，已知寒冷／干燥／炎热原因，以及缺水近似剩余秒数。倒计时归零但消失暂时受阻时显示“等待消失”，检测中断后显示水分尚未确认。不会把同一共用方块的所有植株都显示为同一种植物。

服务端复用 GametophyteStatus，只读既有状态，不重新读群系、搜索水或推进计时。发送固定已知环境原因和位置，客户端核对版本与位置；不发送客户端未使用的配子体周期表。配子体没有身份时不猜测物种，也不提供虚假的健康状态。插件可在Jade配置中切换。

## 构建与可选性

默认使用 compileOnly `maven.modrinth:jade:15.10.5+neoforge`，仓库限定该group；Maven POM已只读验证为HTTP200及对应版本。不把Jade打包进本mod，也不声明为必装依赖。兼容代码不由主模组构造器引用，由Jade发现；没有新增Mixin、方块实体或ticker。

官方接入说明：https://jademc.readthedocs.io/en/1.x/plugins20/getting-started/

无法下载时可给Gradle指定现有jar，原有验证参数继续使用，例如：

```powershell
.\gradlew.bat compileJava --no-daemon --stacktrace "-PjadeApiJar=H:/pcl/.minecraft/versions/航空学1.21.1-NeoForge_21.1.228/mods/[玉 🔍] Jade-1.21.1-NeoForge-15.10.5.jar"
```

该参数只影响编译依赖，不会自动把Jade装入开发运行目录。无本地覆盖参数时默认Maven依赖，不记录个人磁盘路径。
