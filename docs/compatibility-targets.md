# 联动目标与静态核对（2026-10-22）

用户测试环境：Minecraft 1.21.1，NeoForge 21.1.228。以下结果来自用户提供的 JAR 元数据及字节码，只表示静态核对，不表示已启动游戏或完成联动测试。

## 首先处理版本基线

当前项目 `gradle.properties` 使用 `neo_version=21.1.262`，模组描述模板以该值生成最低加载版本。因此当前构建产物不接受 NeoForge 21.1.228。

若以用户整合包为目标，应将编译依赖对齐到 21.1.228，再由用户本地编译和测试。不能只降低描述文件中的最低版本便宣称兼容。尚未调整构建配置，避免在未验证时改变既有成功构建基线。

## 实现边界

- 孢子采集沿用服务器端玩家交互入口，兼容模拟玩家，不要求安装 Create。成功交换袋子后才扣减该孢子结构额度。
- 放置后的采集箱需要实现真实容器及 NeoForge 物品能力，才能供漏斗或外部物流使用。当前手持箱的物品组件库存不等同于已完成方块容器。
- Jade 作为可选联动，读取服务器提供的状态快照；提示查询不应触发大范围水分扫描或修改植物状态。
- 航空学移动结构中的坐标、世界归属、拆装和存档恢复须实测。现有按世界方块位置记录的植物数据，不能直接视为已支持移动结构。
