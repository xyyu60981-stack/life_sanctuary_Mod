# 大叶藓接入与验证边界

第36条已注册`life_sanctuary:large_leaf_moss`方块／物品及共享物种定义。默认一格1株，可同格叠放到3株，始终只有一个UUID、一个基底、一个种群成员；合法基底为原版minecraft:dirt标签。COUNT控制1～3株，CURLED控制卷曲外观，CULTIVATED标识放置来源；具体小树状苔藓模型尚未制作，六种数量／卷曲组合暂用缩放蕨贴图的静态模型。

用户后续确认大叶藓可剪止：新个体canBePruned=true，旧活动计时个体载入时一次迁移、其他旧个体交互时补齐。剪刀能力工具右键走PlantLifecycle.prune，成功才耗1耐久并响剪切音；重复剪不耗耐久、不掉大叶藓、不改COUNT。天然株也能记录剪止，以禁止其手工骨粉增殖；清除此标记后仍保留STATIC，不唤醒天然生长。

剪止立即从独立计时队列移除，清空累计时间但保存原先抽取的目标时长。通过通用状态replace的剪止／解除都会通知独立计时器，不要求未来复苏粉适配器另写特殊入口；解除后同密度周期从0沿用原时长，不重抽。原生骨粉三个入口同时检查剪止，停止增株、扩散及满株骨粉掉物。复苏粉实际物品尚未注册，本批仅接通通用restorePruned接口；不是新增免费的右键解除操作。

存档仍为V1，暂停计时条目保留target和elapsed=0，重载时根据共享个体pruned标记不再排入队列。若玩家手工补株使密度阶段改变，解除后按新密度建立相应周期，而不是错误沿用旧密度周期。共享存储内只绑定所属ServerLevel运行上下文，不写进存档，解除时延迟一刻刷新方块，避免在replace内部触发邻居世界回调。

## 骨粉、干燥与人工生长

非干燥时，1／2株骨粉增加1株；满3株骨粉掉1个大叶藓，原方块仍为3株。干燥群系使用DRY_BIOMES标签，骨粉目标／成功判定都拒绝，不消耗骨粉；无寒冷或水分需求。新放置／初始化时检测一次群系并更新卷曲状态，不每刻检测群系。

手工种植的1／2株每24000～48000活动区块tick增加1株；达到3株后每24000活动tick尝试向相连土壤基底上的空位扩散1格。方向在四个水平相邻基底中随机排序，土壤直接侧面相连，不跨空隙、不替换其他植被、不强制加载区块；上下直接相邻基底的上方已被原株／原基底占用，因此不能额外出苗。目标仍在原16×16种群内，边界处不向相邻种群延伸。

用户明确人工扩散也受种群最多8格约束。本物种以PlantSpreadAdmission(includeCultivated=true)计入天然、人工及自动扩散来源，每格只计1，不按COUNT乘数量；通用旧构造器保持原先不计人工成员的行为，不改变其他植物。此上限限制自动扩散，不额外拦截玩家手动放置；手动超过8格后停止新增自动成员。

天然株不加入生长队列；骨粉或手工补入同一自然格保持原来源，不自动唤醒天然扩散。取回物品后重新种植才作为人工植株。干燥卷曲植株取回、移到非干燥群系重种后恢复；没有持续追踪/填充群系命令的热刷新。公开refresh入口可供后续明确的气候变更通知使用，取消干燥计时后恢复会重新抽取周期，不承诺保留迁移前时间。

## 个体、计时与安全提交

个体与来源登记在PlantIndividuals，只有密度周期放在独立`life_sanctuary_large_leaf_moss` V1 SavedData；复用PlantGrowthScheduler的活动区块时钟、每区块16／每维度128到期回调预算，不占用个体阶段计时、不增加方块实体或随机tick。未加载／未模拟区块不推进，睡觉与修改世界时间不快进。存档捕获elapsed，重载恢复，不保存绝对世界时刻。

一次性方块tick只用于真实放置／生成后的初始化。进入干燥、恢复错误／暂停状态的个体不继续调度。手工补株／骨粉改变密度后重建对应密度周期；满株骨粉仅掉物品，不重置已有扩散计时。破坏、失去基底和活塞破坏注销个体、取消计时，正常掉落实际COUNT数量的大叶藓。

新扩散使用PlantOffspringPlacement与原子结构事务，校验最新父体、种群计数、土壤依赖、空位及所有权；失败不预先占住名额，不使用写世界后才补查额度的方式。父体被通知回调破坏时不保留僵尸计时。密度自己增长不增加个体或补充孢子／种子资源。

未知／损坏计时存档原样保留只读，不重置增长。校验正时长、1～3密度、满株固定1天、elapsed上界、重复UUID与重复坐标；坏档不会当作正常新档重新抽取。

## 天然生成入口

已注册真实Feature类型`life_sanctuary:large_leaf_moss_patch`，使用NoneFeatureConfiguration，仅WorldGenRegion可调用；不支持在已有人工作物的ServerLevel通过/place重复生成，以免绕开共享种群计数。每次只扫描自己16×16区块的256个地表位置，不跨区块读写；符合群系标签、土壤和空气条件，扣除已有地表大叶藓后选择4～8格，不足4格就拒绝。每格密度按100桶精确30%／40%／30%取1／2／3，全部为静止来源；成功后只安排一次服务端初始化tick，世界生成线程不读写SavedData。

独立LargeLeafMossNatural.plan供已加载世界的后续自然种群协调器使用：最多64候选读取，考虑共享计数剩余额度，无写入；调用方还需使用现有单次尝试账本和结构放置事务，不应每次区块加载重抽。

群系标签`life_sanctuary:large_leaf_moss_biomes`包含birch_forest、old_growth_birch_forest、snowy_taiga；“寒带针叶林”按原版积雪针叶林snowy_taiga表达，正式群系数据可调整。**没有新增Configured／PlacedFeature和BiomeModifier，自然种群在群系中的出现频率尚未指定，因此当前不会自动生成大叶藓。** 真实特征和群系准入已准备，正式自然分布激活仍待群系制作接入，不能把Feature注册等同于已自然生成。
