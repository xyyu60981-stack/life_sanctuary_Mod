# 星苔

本体结构照搬地钱（1 像素贴地薄毯）。生殖托有 **3 种**，呈星状。

> 资源名已统一成 ASCII（MC 资源路径不能有中文）。

---

## 1. 文件

| 文件 | 内容 |
|---|---|
| `xingtai_atlas.png` | 56×32 图集（本体 + 三种星形 + 柄） |
| `xingtai_body.json` | 本体：16×1×16 薄毯，1 个元素 |
| `xingtai_receptacle_1.json` | 生殖托 1（2 元素） |
| `xingtai_receptacle_2.json` | 生殖托 2（2 元素） |
| `xingtai_receptacle_3.json` | 生殖托 3（2 元素） |

四个 JSON 都是从你的 bbmodel 直接转的，几何、UV 完全一致，只把贴图路径换成 `life_sanctuary:block/xingtai_atlas`。

## 2. 三个生殖托的区别

三个模型的**几何和位置完全相同**（都是 `5.7~10.3` 见方、y 1.2~1.38 的平板 + 柄），
只有平板**上/下两面的 UV 不同** —— 也就是图集里画了三种不同的星形轮廓：

| | 平板 UV（0..16 空间） |
|---|---|
| 生殖托 1 | `[9.14, 0.29, 12.57, 6]` |
| 生殖托 2 | `[9.14, 10, 12.57, 15.71]` |
| 生殖托 3 | `[12.57, 10, 16, 15.71]` |

所以代码侧只要按权重挑其中一个模型即可，**不需要额外的方块状态**。

## 3. 结构要点

- 平板 `y 1.2~1.38`，厚 0.18 —— 薄但不会消失
- **上下两面用星形贴图，四个侧面用柄那一格**，避免薄边被拉成色带
- 柄 `0.4 × 0.4`，`y 0.2~1.35`

## 4. 代码侧

- 本体：单方块薄毯，和地钱一样
- 生殖托：独立结构（独立方块或方块状态），用 multipart 三个模型等权即可
- 生殖托底部在 y=0.2，叠在本体那 1 像素毯面上正好
