# 枯死石松两格叠放

对应2026-10-27修订第14条。DeadLycopodBlock已提供实际放置、邻居更新与掉落方法，正式材料尚未注册，当前不会新增创造栏物品。现有dead_equisetales是枯死问荆，不复用为枯死石松。

## 注册与表现

物种作者用正式方块ID注册DeadLycopodBlock，构造参数为Properties及明确的基底TagKey<Block>，并注册同ID普通BlockItem。不设置requiresCorrectToolForDrops，因为掉落已通过NeoForge剪刀能力判断；如果额外设置此标志，原版玩家破坏流程可能在调用掉落前拒绝收获。选框、碰撞、材质、音效由正式材料属性及模型确定。

方块状态part有single、lower、upper三种，分别映射单格枯死石松、中型下部、中型上部模型；三个状态掉落与创造选取均指向同一种普通物品，不创建独立“中型物品”。CODEC保存基底标签引用，数据包实际提供该标签内容，不硬编码猜测土壤。

第一份放在合法基底为single；第二份放到其上为upper，下方通过原版邻居形状更新归一为lower。第三份不能再叠放。upper在放置更新的短暂过渡期接受single或lower作为下方，稳定后为lower／upper。下方必须是真正基底，同方块即便被误加入基底标签也不允许突破两格上限。

## 破坏

直接破坏格子的工具具有ItemAbilities.SHEARS_DIG时，getDrops固定返回本物品1个；普通工具、爆炸、无工具连带移除不掉落，精准与时运不另加数量。兼容正确声明该能力的其他模组剪刀，不按具体剪刀物品ID白名单判断。

- 剪上格：直接上格掉1，下方邻居更新变回single。
- 剪下格：直接下格掉1，上格因失去下部返回空气；原版连带移除不传递玩家剪刀，因而不再掉第二个。
- 失去基底：下部和上部依次消失，均无剪刀掉落。
- 活塞：使用DESTROY，不能把上下两段分别推成悬空结构；无工具破坏无掉落。

不要再叠加额外方块破坏事件掉落或与玩家工具相同的“递归破坏上方”处理，否则会重复发放。若将来为其他环境增加特殊回收入口，应沿用直接／连带原因区别。

全部状态由原版BlockState保存，无活体种群身份、方块实体、随机tick或调度任务。正常渲染使用烘焙模型。
