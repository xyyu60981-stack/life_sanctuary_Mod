# placed/ —— 剪下插回去的装饰丛

对应方块 `life_sanctuary:placed_equisetum_arvense`，状态只有两个：

| 属性 | 取值 | 说明 |
|---|---|---|
| `nutritional_stems` | 0 – 3 | 插了几根营养茎 |
| `spore_stem` | true / false | 有没有插一根孢子茎 |

方块只有一格，所以模型必须压进 16 像素：

- 营养茎按 **0.66** 缩放（23.2 → 15.3 像素）
- 孢子茎本来 15.8 像素，不用缩

## 文件

| 文件 | 内容 |
|---|---|
| `horsetail_placed_c{1,2,3}.json` | 1 / 2 / 3 根营养茎，摆位同丛生（居中 / 对角 / 三角） |
| `horsetail_placed_spore_c{0,1,2,3}_{straw,rust}.json` | 孢子茎，按根数选空位；两种材质 3:1 随机 |
| `blockstate.json` | 方块状态草稿，可直接替换现有文件 |

共 11 个模型。

## 说明

- 摆位不随孢子茎变化（营养茎位置只由根数决定），孢子茎只找空位插
- 孢子茎材质走带权变体，不需要存档字段
- 这套是**装饰**：没有种群、没有生长计时、没有采集额度
