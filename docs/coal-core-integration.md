# 煤核生成与食品配置接入

对应2026-10-27第26／27条。用户已明确煤核以Y=0为中心，实际生成范围Y=-10～10，包含端点。本页中的生成器已注册，配置数据与正式材料尚未激活。

## 田字萍粥

物品作者在真实田字萍粥注册时使用PlantFoodProfiles.marsileaPorridge，营养10、饱和0，原版FoodProperties的单个概率效果：MobEffects.HUNGER、100tick、amplifier0、概率0.30。没有把问荆粥改为该食品；现有问荆粥抗火配置保持原样。

此方法不注册猜测ID、不增加碗回收或改变放置行为；田字萍粥的可放置物品与模型、两种萍孢子叶配方仍待具体材料作者接入。不要再次给同一物品追加一份相同效果或另挂食用事件，避免重复判定概率。

## 煤核配置

特征类型life_sanctuary:coal_core，Configuration通过CODEC提供：coal_blocks（真实矿化材料标签）、enriched_biomes（煤沼／成煤森林标签）、scattered材料表、structures模板表、structure_chance、base_attempts、enriched_attempts、maximum_cores。未提供默认ConfiguredFeature／PlacedFeature，稀疏频率及两类比例须由正式群系配置明确设置。

Material包含stone状态及可选deepslate状态。目标宿主为原版石头时使用stone，为原版深板岩时须有deepslate；否则该煤核不可放置。完整煤化块可在两种宿主配置同一煤化状态；镶嵌方块可分别使用石头／深板岩背景；仅适合石头的印痕不必伪造深板岩版本。正式材料按第28条接入，不能把通用木材或原版煤矿石冒充指定古植物煤化块。

Template具有唯一id及1～512个Part（相对offset与Material）。偏移XZ各不超过±16、Y不超过±20，Y跨度不能超过20；四种水平旋转整份应用，并通过NeoForge上下文旋转API同步状态朝向。重复坐标、超高／超大模板和实体／流体材料拒绝。模板用于作者提供的较完整植物形态，不在共享代码中编造物种树形。

## 生成流程

每次特征调用在origin区块取候选XZ。基础尝试1～3次；额外尝试1～8次只允许地表命中指定本模组群系标签的坐标，按地表WORLD_SURFACE_WG所在群系判断，不把地下洞穴群系误当作煤沼／成煤森林。单次最多2～4个成功煤核，且配置上限高于基础尝试数，给增量候选留下容量。实际丰度仍由PlacedFeature频率控制。

每个候选只选一次零散材料或一次完整模板及旋转。模板先计算所有部件都能落在-10～10及世界高度内的合法锚点范围，再抽高度；虚拟锚点可在带外，但实际煤化块没有一格越过该带。不因模板高而截成残体。零散形式为单个材料，各次候选自然分布于不同位置；较完整形式按作者模板整体放置。

整份先检查全部目标：区块可读、生成区域可写、实际石头／深板岩宿主、干燥无实体、宿主材料存在、旋转后仍属coal_blocks且无流体／实体。不替换矿物、空气、地下水、容器或现有煤核，不强制加载区块；受阻跳过这一候选，不轮流换方向、换形态重试。允许模板在生成区域支持的相邻区块内展开，但每一格均须已可读可写。

写入前再比对全部原状态，写入过程中核对尚未写的宿主。写失败时仅回退本批实际尝试且仍等于本批替换值的格子；第三方改成其他方块时不覆盖，返回RECOVERY_REQUIRED、记录警告并停止本次特征后续尝试。正常失败回退不算生成成功。材料方块需保持静态、无实体和无外部放置／移除副作用，共享回退不承诺撤回其他模组已生成的实体或物品。

煤核只有地形中的静态方块，无活体身份、种群、成熟计时或方块tick。生成工作线程不写植物SavedData。煤化／印痕状态由原版方块存档保存。

## 验证边界

全源码独立javac（开启弃用检查）通过，未运行Gradle。规则检查覆盖-10／10端点、20高模板、合法锚点与世界高度交集、四分之一旋转、越界／重复／极值偏移拒绝、首次写前完整预检、失败／异常回退及第三方方块保留。食品概率／时长／等级元数据核对通过；原生食品效果类在独立运行环境需要Minecraft注册表启动，故没有以无启动环境的测试声称实际吃粥效果已验证。

正式煤化材料、模板、群系标签和PlacedFeature频率尚未生成，真实食用、石头／深板岩宿主选择、跨区块模板、世界生成阶段和丰度需要后续游戏验证。
