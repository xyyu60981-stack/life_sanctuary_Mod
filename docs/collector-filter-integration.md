# 采集箱名单设置

对应2026-10-27修订第24条。此项已接入现有普通／Plus采集箱、实际菜单与界面，不是只提供未来物种接口。游戏联调仍未执行。

## 玩家操作

打开物品、装备或放置的采集箱，在右上角点“名单”。光标须先放下真实物品，才可安全切换菜单。名单页有18个样本格和原版玩家背包槽：

- 模式按钮依次关闭、黑名单、白名单；条目在模式切换时保留。黑名单拒绝命中的产物，白名单只收命中产物，空白白名单不收产物。
- 拿起背包中的真实样本，拖入／左键名单格，复制物品种类及其物种；不消耗样本，不把样本寄存进名单。
- 持样本右键名单格，复制该物品种类的通用条目，不区分物种。孢子袋／花粉袋虽共用物品ID，也可按物种精确区分。
- 空手左键拖已有图标到另一格，交换条目；空手右键删除。重复添加完全相同条目会移动原条目，不堆出重复项。排序仅方便整理，命中按所有条目的并集，不采用隐藏的首条优先规则。
- 悬停显示物品名及物种／通用匹配说明。未注册的旧条目保留原ID，以屏障图标显示，不静默删除。
- “清空重置”清全部条目并关闭过滤；“返回”回到当前采集箱内容页。光标有真实物品时不切换菜单；关闭时由原版处理光标归还，样本槽不作为真实物品清空或掉落。

空孢子袋、空花粉袋是采集耗材，始终允许补充，不作为名单样本。名单控制产物，不扩大原collector_contents准入标签、不允许嵌套采集箱。设置不会删除或锁死箱中原有物品，旧内容仍可取出。

## 服务端与收集入口

OpenCollectorFilterPayload只发送当前菜单ID，服务器从已打开的CollectorItemMenu或CollectorBlockMenu推导真实箱子，不接受客户端物品栈或远程坐标。每次编辑检查存活、非旁观、原箱子引用／槽位或方块距离有效；移动或替换箱子后旧界面不能继续修改。

样本复制只读服务器getCarried，不能凭客户端发送的图标创建规则或真实物品。18个样本Slot均禁止pickup和mayPlace；菜单拦截样本的换手、数字键、快速搬运、克隆、丢弃与拖放转移。只会复制规则，不修改真实光标数量。玩家背包原箱槽锁定，避免配置期间把箱子搬走。真实防复制行为仍需游戏用各点击类型复测。

拖动重排使用原版container button协议，分SELECT32～49、MOVE64～81两条命令，均在有符号byte范围。服务端记录选择时不可变名单快照，落点操作若遇其他编辑已改变名单则拒绝，防止拖动期间覆盖新设置。模式、重置和返回为0、1、2。未知命令拒绝。

名单实际接入CollectorInventory.insert（装备拾取）、exchangeBag（物种实际满袋交换）、CollectorItemHandler.isItemValid及放置箱canPlaceItem。仍保留全局服务器拾取黑名单等既有条件。产物若拒绝，在复制容器、消耗空袋及采集次数前返回；物种必须沿用原采集事务的“交换成功后才扣额度”顺序。

hasEmptyBag仅做物种无关的实际空袋存在检查，不再拿问荆满袋充当所有物种预检。真正空间／匹配堆叠和过滤由实际产物的原子exchangeBag检查；满箱消耗单个空袋腾位的逻辑保留。Create机械手直接手持空袋的原流程不被采集箱名单替代；若其产物送入放置采集箱，正常能力插入需遵守目标箱名单。

## 存储与性能

配置在箱子CUSTOM_DATA中的CollectorFilter，版本1，包含Mode和18格有界规则。每条保存槽位、真实物品ID、物种字符串（空字符串为通用）。不保存整份ItemStack或容器，不使样本带出嵌套物品或任意组件。

缺配置保持原先允许产物的行为；未知版本、缺字段、重复槽／重复规则或无效物种标为BROKEN，拒绝新产物且保留原数据，只有显式重置能替换损坏配置。重置只移除名单键，其他模组CustomData保留。

组件为不可变值，以CustomData身份为弱键、有界512项缓存解析结果；插入和漏斗逐槽校验不会反复复制、解析18条NBT。配置变更产生新组件身份，立即使用新规则，不缓存可变箱子库存。未增加世界扫描或采集箱方块ticker。

CollectorBlockEntity通过原版components保存同一CUSTOM_DATA，setFilter保留其余组件；两种箱子掉落表均复制custom_data。创造破坏时，即便没有内容但有名单配置也保存为物品。升级配方原transmuteCopy保留全部组件，因而保留名单。名单重置为空且关闭时移除名单键，不留下无效默认配置。

新增独立菜单类型collector_item、collector_block、collector_filter；原collector_hover继续悬停／B键路径。手持右键使用普通居中、显式关闭的界面，不错误套用悬停锚点或自动关闭。方块同样用专用箱菜单，避免给所有原版箱子界面加按钮。

## 验证边界

全部源码独立javac并开启弃用检查通过。规则程序检查物种精确／通用匹配、关闭／黑／白模式、空白白名单、重复规则移动、不可变拖动、NBT往返、外部数据保留、损坏配置拒绝和显式重置、有界组件缓存及按钮协议范围。语言和掉落表JSON语法检查通过。

# 2026-10-29 物种标签别名与显示补充

采集结果常使用短物种标签，指令／其他注册入口也可能提供完整ID。Rule.matches现将短标签按life_sanctuary命名空间解析后比较，因此lichen_photobiont与life_sanctuary:lichen_photobiont是同一物种；other:lichen_photobiont仍然不同。只调整匹配，不改写既有袋子或已保存过滤器的原始标签。显式编辑过滤器时会移除同物品、同物种别名的重复条目；加载旧配置不擅自折叠条目。

孢子袋／花粉袋名称通过共享species语言键显示物种，大小／混合孢子形式继续保留。空袋或无效标签不拼出虚假物种名，未知有效物种回退完整ID。名称只是Component，不参与物品ID、组件堆叠或名单匹配。

独立javac与20项命名／过滤规则检查通过，包含短／完整标签双向匹配、外部命名空间隔离、空／损坏标签拒绝、显式去重及原始标签保存重载；实际菜单／采集交换仍待游戏验证。
