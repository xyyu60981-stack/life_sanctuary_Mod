## 已转换资源

- 两份16×1×16原生薄毯模型base_soil／base_stone；本体不平移、不旋转，不增加东西南北邻接状态。
- 土面原样复制已确认的64×64无缝PNG；石面从已确认的1254×1254无缝PNG以环绕邻域Lanczos缩至64×64，避免缩图边缘采用夹取采样。原始文件不修改。
- 顶面明确UV=[0,0,16,16]，同时解决土面bbmodel使用32单位UV网格而方案示例写16的差异。侧面读取同一贴图相应边缘的一行／列，底面沿用同图并启用向下剔除。
- 生殖托沿用用户的16×16色板。1～2雌＋固定3雄，共有4套预烘焙错位组合，计8份组合模型；托中心各自加入不超过0.6模型像素的XZ偏移，全部留在该格内。
- 使用原生加权模型按方块位置稳定选择组合；不每帧随机、不增加方块实体、动态渲染或邻块扫描。满格本体与托使用分离multipart，避免花朵式整块偏移破坏地毯边界。

生成器为tools/import_marchantia_assets.py，输入用户原始模型目录，可重复生成。用户随后确认物种／方块／物品ID为marchantia_polymorpha，绑定现已启用，并与marchantia-blockstate.example.json同步；只列surface=soil/stone、reproductive和female_count三个属性。
