# 植物环境规则与已确认修订

## 来源优先级

用户在本会话中的明确修订 > life_sanctuary_植物水分与气候需求.xlsx > 旧制作大纲。
新表与旧大纲冲突时以新表为准。工作簿原文件不在本仓库内，本文记录确认后的覆盖规则，不代表所有物种已实现。

## 已确认覆盖规则

| 物种／范围 | 最终规则 |
| --- | --- |
| 问荆 | 全阶段无需临水，不注册水分检查。 |
| 裸蕨类 | 以着生基底为中心，XYZ 5×3×5 方盒内检测水源或流水；不用圆柱范围。 |
| 银蕨水分模板 | 以基底为中心，XYZ 9×3×9；仅明确沿用模板的阶段适用。 |
| 桅木配子体 | 排水后进入缺水消失程序；未另定时限时采用1游戏日。生长阶段另按新表。 |
| 皮奇树蕨 | 保留配子体、树苗缺水800～1000 tick消失的特例；成年移水不死亡。 |
| 王蕨、观音莲座蕨 | 寒冷默认停止生长；配子体、幼苗缺水消失。失叶是亚成体和成年的特性，不套用到幼苗。 |
| 鳞印木、广德木幼苗 | 干燥导致死亡时变为枯死石松，不直接消失。 |
| 灰黑蕨成株及桩 | 寒冷1游戏日后枯死；不沿用配子体的2000～3000 tick。 |
| 极端群系 | 指对应列的干燥／寒冷／炎热标签，不新增一套极端标签。 |

## 通用规则

- 1游戏日为24000 tick。干燥、寒冷、炎热为独立条件，允许同时成立；不能用互斥枚举代替完整气候条件。
- 水分独立于群系。范围按XYZ解释，通常以着生基底为中心。
- 配子体死亡统一消失。其他阶段按物种指定消失、枯死形态或可逆失叶。
- STATIC不参与群系、水分检测或环境衰退；只有PLAYER、ONE_TIME参与。
- 正常水分成员按种群每5000 tick检测；缺水成员独立每1000 tick复查，恢复供水后取消缺水倒计时并返回原种群正常组，不重置其他成员的周期。
- 800～1000 tick等短死亡时限必须在到期时再次检查供水，不能强制等到1000 tick才处理。
- 气候通常只检测一次。阶段变化保留气候事实，但需按新阶段重新判断响应。
- 缺水、气候等衰退原因独立保存；补水不能取消气候衰退。
- 气候导致停止生长、待枯死、待消失时，骨粉无效且不消耗；必须在isValidBonemealTarget拒绝使用，仅在成功率判定返回false仍可能消耗骨粉。
- Jade查询读取缓存，不触发水体扫描。未加载区块不主动加载，不做离线生长或死亡演算。

## 当前实现边界

水分调度及方盒搜索框架已提供，默认搜索中心现为植株下方基底，可由具体物种覆盖。
物种水深、邻水种植、多基底、失叶恢复、气候组合响应及Jade显示仍需逐项接入。
PlantClimate独立保存干燥、寒冷、炎热三个条件；旧PlantEnvironmentState只作为兼容摘要，不用于组合判断。
问荆已接入寒冷停止阶段生长、扩散及骨粉催熟；同株阶段转换保留个体数据。其他物种气候响应尚未全部接入。
HorsetailPopulations.statusAt提供只读快照，HorsetailStatus.toTag提供未来Jade服务端传输数据；两者不刷新群系、不扫描水体。UNKNOWN与STATIC分别报告，避免把未检测状态显示为适宜。实际Jade插件注册、客户端文字和同步尚未接入；MaturityTicks目前仅为保存字段，不代表完整成熟倒计时已运行。
