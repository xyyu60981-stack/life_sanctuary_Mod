# 基础架构现状与后续制作顺序

截至2026-10-29，大部分共享底层逻辑已具备实现，可以转入具体内容接入。这里的“已具备”表示代码和接口存在，不表示所有物种已启用或游戏联调通过。本文作为当前入口；历史进度按开发时间记录，其中较早的待办可能已经被后续工作替代。

## 已具备的共享基础

| 模块 | 当前能力 | 仍需完成的落地工作 |
| --- | --- | --- |
| 个体、种群、阶段 | 身份与基底归属、结构索引、阶段计时、剪止、暂停、持久化与坏档保留 | 各物种注册；旧数据迁移与保存重进实测 |
| 多方块植物 | 空间预检、结构提交与回滚、部件归属、连锁移除、流体恢复 | 各阶段实际结构模板、破坏与跨区块实测 |
| 生长与繁殖 | 叶片与芽丛、补叶额度、苏铁传粉、异孢配子体、走茎与地下茎规则 | 正式物种成长、采集和出生适配；不能只注册外观 |
| 环境 | 气候暂停、正常按种群5000刻查水、缺水按个体1000刻复查、消失事务 | 按已确认环境表逐物种绑定；缺水补水与卸载实测 |
| 共用配子体 | 六类方块与物品、物种标签、播种与培育放置入口、幼苗转换适配 | 正式外观、含水形态、各物种基底与幼苗模板 |
| 采集箱与培养柜 | 容器、UI、过滤、袋子交换、培育进度和自动输入输出 | 每个产物的真实方案；多人、漏斗、满箱与连接柜实测 |
| Jade与自动化 | 已注册配子体、问荆、采集箱和培养柜提示；已有机械手兼容代码 | Jade安装／未安装启动，机械手Mixin与真实交互验证 |
| 材料与功能设备 | 炭化／煤化等规则接口、切片机、展示柜、商人和指南针基础 | 材料注册、配方、结构、目标搜索与最终美术 |
| 小游戏 | 服务端回合规则、关卡工厂、进度／奖励资格与保存；掌机应用壳 | 棋盘联网UI、正式关卡、奖励库存交付和完整游玩联调 |

## 不能划为已完成的内容

- 全部物种的实际方块、模型、贴图、阶段结构、配方和自然生成。
- 全部39项修订的最终交付。部分修订目前仅有共享规则与适配接口。
- 共用配子体的完整含水／流水表现；现有占位资源不能作为正式美术。
- 小游戏可完整游玩的客户端链路。
- 目标NeoForge 21.1.228的完整运行、专用服务器、多人、防复制、保存重启及大规模农场性能验证。

最近的独立javac使用本机NeoForge 21.1.262缓存与Jade15.10.5，不替代目标版本验证；Codex未运行Gradle或Minecraft。用户反馈的逐批编译成功也不能代替游戏行为验证。

## 后续顺序

1. 先完成问荆纵向闭环：袋播种→配子体→单格幼株→双格成株→采集／剪止／破坏→保存重进。同步核对上下格模型、额度与泥炭规则、培养柜产物、Jade提示。
2. 让物种作者按现有接入文档提供实际阶段模板、基底、时间与资源；只有遇到真实缺口才扩展共享层，避免重复建立同类框架。
3. 分别接入一个树蕨、苏铁、异孢乔木石松和芦木，验证独立叶片、传粉、雌雄配子体及同源地下茎四条复杂链路。
4. 补自然生成、材料设备内容和小游戏客户端链路；按模块完成可游玩的内容。
5. 进行兼容与规模验证：Jade可选性、机械手、航空学、跨区块、卸载恢复和批量成熟。是否达标以实际测量为准。
