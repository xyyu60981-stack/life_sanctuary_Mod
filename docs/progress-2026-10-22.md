# 开发进度汇总：2026-10-22

本次归档包括此前未提交的基础功能，以及本轮通用植物架构的连续开发成果。
编译基线：Minecraft 1.21.1、NeoForge 21.1.228、Java 21。

## 已归档的功能与接口

- 采集箱与 Plus：方块容器、内容物交互预览、快捷打开、采集袋库存处理及可选机械动力适配代码。
- 问荆：按实际结构记录采集额度；破坏与手工取回、装饰性重新摆放、孢子茎食用及掉落资源调整。
- 环境与泥炭：气候响应、水分监测、泥炭基底与植物互动接口；已确认规则另见环境与泥炭文档。
- 通用植物个体：物种元数据、来源与出生途径、阶段、剪止、暂停原因、成长计时及结构归属。
- 存档版本 5：采集额度、独立繁殖额度和可选走茎额度分别保存；兼容旧版本，异常数据保留并只读保护。
- 调度与种群：按活动区块计时，限制到期回调数量；维护派生种群计数，提供扩散准入。
- 结构提交：快照预检、归属检查、完整结构写入、失败回退及恢复诊断；自然多方块生成具有一次尝试记录。
- 子体生成：与种群登记衔接，支持成功提交时扣除亲本繁殖额度，失败不提前消耗。
- 走茎：水平无环连通图；拆分／合并方案、资源与计时继承、长度及分叉准入、预算存档和单段延伸提交。
- 保水结构：新增、修改及移除保持相同水状态；移除恢复水方块；实际方块变化仍走原版侦测器通知路径。

## 验证情况与边界

用户已在本地 PowerShell 多次执行 compileJava 并反馈成功，包括最终侦测器通知调整。
本会话按用户要求没有在 Codex 中运行 Gradle；执行了代码阅读、接口核对和 Git 差异检查。
编译通过不代表游戏行为已验证：通用架构多数尚未接入具体物种；Mixin、界面、红石及存档往返仍需游戏测试。
结构回退不能撤销第三方回调的所有副作用，也不是世界区块与 SavedData 跨文件的崩溃原子事务。
