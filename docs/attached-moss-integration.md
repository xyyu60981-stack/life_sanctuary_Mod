# 附着藓接入记录

物种、方块和物品 ID：`life_sanctuary:attached_moss`。

## 已接入

- 使用提供的四变体图集和单片双面平面模型，四个水平朝向分别随机选择变体。保留当前贴图，包括已确认暂不修正的上下边缘色差。
- 每格保存 north/east/south/west 四个附着面；各面必须直接依附完整方块侧面，不支持顶面、底面或悬挂藤蔓链。
- 加入原版 climbable 标签，可攀爬；没有实体碰撞。选择框按附着面缓存为 16 种组合。
- 支撑失效时仅移除对应面，最后一个面失效后消失。剪刀破坏整格掉落一个物品。
- 不自动扩展，没有随机 tick、方块实体、成长计时或生殖结构。
- 骨粉从合法候选中随机扩展一个面：沿现有面四周扩展，或扩展到本格相连的另一合法侧面。无种群数量上限；寒冷环境无效，无合法候选时无效。
- 注册物种分类、创造模式物品、名称和 60% 堆肥概率。

## 自然生成待接入

已记录规则常量：每群 1～4 个，群间至少间隔一个区块，偏好距地面 10 格以内的原木、石头和圆石侧面。已注册自然生成 Feature 类型 `life_sanctuary:attached_moss_patch`，尚未添加 configured/placed feature 或群系投放，不能据此声称世界中会自然出现。群系清单及生成频率尚待确定。

`AttachedMossNaturalPlan` 已完成纯布局准备：世界种子确定两轴奇偶相位，只有每隔一个区块的候选区块允许自然群落，以无需读取相邻区块存档的方式保证间隔。该网格只表示可生成区域，不代表每个候选区块必生成；实际生成概率由后续投放入口处理。正、负坐标采用同一规则，不依赖区块生成顺序。

调用方需先确认合法暴露侧面、完整支撑、首选基底及距地面高度，再提供候选。规划器拒绝跨区块的位置和支撑、重复侧面及非水平方向；候选按坐标排序以保持同种子结果与输入顺序无关，优先在首选侧面选起点，并在起点曼哈顿距离3以内选取至多4个不同方块位置。候选不足时保留至少一个合法位置，符合1～4格范围。同格多个候选面不重复计数；输出及输入位置快照不可变。

该纯规划模块不读取世界、群系、SavedData，不放置方块，也不启动扫描或 tick。人工骨粉扩展不使用此网格或自然数量限制。

## 地形筛选与生成入口

`AttachedMossFeature` 先检查种子网格与配置的 `chunk_chance`，再检查当前区块内部14×14列；保留一格边缘使附着位置及侧面支撑都在同一区块内。每列从忽略树叶的高度图开始，至多向下64格，跳过原木、树叶、非完整碰撞和自然植物排除标签，取首个完整地面。找不到地面就跳过该列，不继续向下无限搜索。该方法是有界的地面近似，不声称识别所有模组树木和人工建筑。

只扫描该地面上方1～10格空气位置，过滤 `life_sanctuary:attached_moss_biomes` 标签，要求直接完整侧面支撑并排除禁止自然生成的基底。首选基底标签 `life_sanctuary:attached_moss_preferred_supports` 默认含原木、石头、圆石和苔石，未首选但完整的其他合法侧面仍可作为回退候选。扫描带内已有附着藓时放弃本次群落，避免同一入口重复加群。

选定整群后预检所有目标，实际写入前再次检查空气与支撑；失败时回退已写入且仍为本次目标状态的位置。自然附着藓不登记个体、不排入成长 tick，也不读取 SavedData。当前群系标签为空，且没有实际投放文件；`chunk_chance` 是无默认值的必填字段，待生成频率确认后再启用。
