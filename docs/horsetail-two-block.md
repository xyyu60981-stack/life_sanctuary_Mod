# 问荆成年体双格状态接口

`life_sanctuary:equisetum_arvense_sprouts` 是独立的单格幼株，不存在 `part=upper`。仅 `life_sanctuary:equisetum_arvense` 成年体具有 `part=lower|upper`、`growing`、`nutritional_stems`、`spore_stem`、`withering` 状态。上下格都使用成年方块 ID，种群、采集额度和生长计时只保存在下半格的基底位置。

物品放置和幼株长大都先检查上方方块可被替换、无流体且高度合法，再建立上下两格；上方不足时幼株保持原状并延后重试。潜行右键取回、准星取物和空袋采集可命中上下任一格，均以同一株的下半格结算。破坏其中一格会清理另一格，另一格不另行掉落。上下格的茎数量、孢子茎和其他视觉状态保持同步。

`growing=true` 用于仍有扩散机会的玩家成年株；达到当前扩散额度后转为 `false`。自然静止株和一次性来源默认 `false`。现已接入V8上下格拆分模型，按下格坐标同步随机高度。growing仍为扩散流程状态，不映射资源中“最新一根是幼株”的j模型；独立幼株不配置成年上格。实际游戏中的上下格联动、破坏掉落和观察者更新仍需联调。

## 其他跨两格方块的接入约定

像原版玫瑰丛这样不可拆开的活植株，用同一个方块 ID 和 `part=lower|upper` 表示两半。放置或阶段成长前检查两格，种群与采集状态只登记在下半格；任一半失去另一半或基底时成组清理，玩家直接破坏只结算一次掉落。命中上半格的采集、工具和信息显示先定位下半格，再读写个体数据。模型资源按 `part` 分开，幼株等单格阶段不得提前占用上半格。跨区块时只依据基底归属种群，不因为上半格进入另一区块而重复登记。

`DeadLycopodBlock` 是有意不同的叠放装饰：它允许一份保持 `single`，放第二份后才成为 `lower/upper`，剪去上半格会重新成为单格。这类可拆叠放结构不能套用活植株的整株清理规则。芦木地下茎覆盖原版双格草花时使用 `RhizomeDecorationCleanup` 成组清理；活体问荆不属于可无掉落顶掉的装饰。
