# 新增苏铁基础参数

第37条以CycadGrowthProfile.COMMON登记共享物种`life_sanctuary:cycas`，中文为用户新增的“苏铁”。没有擅自指定某个拉丁种名，也没有创建模型／物品的假ID。当前注册的是物种元数据、成长图、种群规则与空间门槛，不是完整可种植的方块物种。

## 形态和自然群体

成年高度3～8格；只有高度严格大于5格才允许分支，预算1～2次。sampleHeight、sampleBranchBudget供结构适配器一次选择参数，permitsShape拒绝矮株分枝或超过2次。分支是许可，0次也合法；没有给“可以分支”擅加固定概率，也不强迫每株高个体都分叉。具体高度／分支参数应随正式成长方案保存，不在空间失败后每tick重新抽取。

叶片以DARK_GREEN语义色板表达，具体RGB、材质和叶片几何由模型作者决定，不给缺失的配色填假精确值。

自然群体人数5～12，32×32种群；侧芽OFFSHOOT不计入成员上限，其余已声明主株阶段计入自动扩散规则。人工来源的默认计数策略保持通用规则，与大叶藓特有的includeCultivated=true无关。自然群系标签life_sanctuary:cycas_biomes包含minecraft:savanna和minecraft:plains；没有擅自扩大到稀树草原高原、向日葵平原或其他模组群系。

没有激活自然生成、阶段概率、活动母株选取或侧芽生成。样本群体5～12的函数不等于已写入世界；自然静止／活动株和同群性别组成须继续使用正式苏铁适配规则。

## 沿用天窗苏铁的成长部分

- SEED→SAPLING：1～3天。
- SAPLING→SUBADULT：2～4天。
- SUBADULT→ADULT：1～2天。
- 采下重种的OFFSHOOT→SUBADULT：1～3天。
- ADULT为明确完全成年阶段，其他阶段不提前取得孢子／种子采集资格。

自然侧芽仍应以静止来源保留，不因定义中存在OFFSHOOT转换就自行长大；源权限和物种适配器决定是否启动计时。骨粉沿天窗苏铁无效，acceptsBonemeal=false供实际方块使用。

已注册小苗成长的XYZ3×1×3、亚成成长的3×2×3只读门槛，接入现有阶段／底层结构事务检查。它们不代替完整新形状空间预检，也不代替天窗苏铁的高阶段邻株竞争和侧芽排除规则。

开花、供粉、三次2000刻受精、32×32种群／末次21×5×21及+20个百分点等继续由PlantCycadRules／PlantNaturalPollination提供。具体物种需要提供明确SeedYield及供粉资格后注册，不把旧果锥5～10误当新种子产量。当前没有为新苏铁登记猜测产种值、花实体、侧芽系统、基底／环境条件或掉落。
