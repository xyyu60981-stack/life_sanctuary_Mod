# 问荆破坏与摆放验证

本轮仅完成代码及资源静态检查；请在本地编译后进行以下游戏验证。

## 规则

- 活体成年问荆普通破坏、剪刀左键破坏、精准采集均按实际营养茎数和孢子茎数掉落，不掉草杆，不保留生长数据到物品。
- 活体三个阶段、摆放植株均被活塞摧毁而非推动；失去有效基底也通过原版破坏路径掉落。阶段自然转换仍保留种群数据。
- 营养茎物品放置为独立的摆放方块；可以组合 1～3 根营养茎及 0～1 根孢子茎，也可单独摆放一根孢子茎。不能叠加到任何活植株。
- 摆放植株不生长、繁殖、采孢子或创建种群，无 tick 或方块实体。
- 潜行右键取回准星命中的一根茎（持物也可）。主手处理一次，机器手不执行手工取回。优先进入背包并播放拾取音效；装不下则在玩家旁掉落，当次不播放拾取音效。
- 取走活体孢子茎后，该位置保留耗尽额度，不能借取回刷新额度。保留营养茎时保留种群、成熟及环境等记录。
- 取走最后一根营养茎后，若还有孢子茎，将其转为摆放状态，清理该位置活体数据；没有孢子茎则变为空气。
- 孢子茎食用时间 10 tick，饥饿恢复 2，饱和恢复 0。饱腹时遵循原版不可进食规则。
- 保留原物品 ID；旧版本独立孢子茎方块现在视为摆放植株，不再能刷新采集次数。

## 验证清单

| 场景 | 预期 |
| --- | --- |
| 活体每种 1～3 根营养茎、带/不带孢子茎组合，分别普通/剪刀/精准采集破坏 | 掉落计数分别完全一致，没有草杆或重复掉落 |
| 活体/摆放植株被活塞顶到或基底移除 | 原位置清空、只掉一次物品，活体状态清理 |
| 原位置重新由配子体开始生长 | 不继承旧种群、剪止、成熟计时或采集额度 |
| 摆放单根营养茎并继续添加 | 最多 3 根，可加 1 根孢子茎 |
| 先摆放孢子茎再添加营养茎 | 成功组合；不能添加第二根孢子茎 |
| 对自然/人工活体使用茎物品 | 不改变活体内部茎数；相邻有效位置可按原版规则摆放 |
| 分别瞄准四处可见茎，潜行右键 | 每次只取回对应类型一根，剩余外形和数量一致 |
| 创造模式分别瞄准营养茎/孢子茎，按中键 | 获得对应茎物品；活体与混合摆放植株均一致，不携带种群或采集额度 |
| 连续取回后再整格破坏 | 取回数量加掉落数量等于原始数量 |
| 背包有空间/只剩可合并位置/全满 | 前两者入包有声音；全满掉地上，无当次拾取声音 |
| 孢子茎取回、重新摆放、存档重进后用采集箱交互 | 不产生新孢子 |
| 最后一根营养茎取回，仍剩孢子茎 | 仅保留摆放孢子茎，不再生长或扩散 |
| 生存模式非饱腹食用孢子茎 | 10 tick 消耗 1 个，饥饿 +2、饱和 +0 |
