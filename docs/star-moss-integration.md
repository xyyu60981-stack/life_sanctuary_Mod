# 星苔接入

沿用物品ID对照表中的 `life_sanctuary:marchantia_stellatus` 作为物种、方块、物品 ID；显示名称为星苔，不以该历史 ID 宣称科学分类。

## 模型与资源

来源：`E:\生命庇护所资源文件\模型资源\星苔`。四个原始 bbmodel 内嵌图集与外置图集有383个像素不同；用户已选定外置 `xingtai_atlas.png`，与 `星苔_atlas_1.png` 像素一致。原始目录没有修改，项目只复制56×32小图集，不引入大尺寸参考图片。

本体保持原始16×1×16薄毯，UV和形状沿用提供的原生 JSON；生殖托原模型最高1.38像素。每次促成繁殖时选择2～5个生殖托，整格共用一次采集额度，数量不会乘算产出。每个数量预烘焙8套排列，生殖托分别从三个模型随机选取，在五个固定候选中心上作小幅错位；原版位置随机选择保持显示稳定。共33个方块模型，无自定义方块实体渲染，不逐帧掷随机数。

工具：`tools/import_star_moss_assets.py --source <原始目录>`。运行将重新生成上述模型、图集副本、8种 blockstate 和本体物品模型。物品暂用本体模型，无独立手绘物品图标。

## 行为

- 孢子袋播种、普通物品放置和扩散直接形成成年薄毯；未添加幼苗阶段。
- 合法基底采用完整上表面，不沿用地钱土／石两套材质；基底失效则消失。普通破坏无本体，剪刀／精准采集掉1个本体；活塞按小植物销毁；堆肥60%。
- 干燥、寒冷、炎热均不阻止星苔生长，无临水需求。不作气候扫描，不保存虚构的寒冷暂停状态。
- 每次独立人工种植建立独立组；原株和后代合计最多16格，限同一16×16区域；后代继承组标识，原株移除或重载不重置上限。每28800～48000有效刻尝试扩散，同高度优先，其次上下1格。
- 扩散受阻或组已满，改为等待10000～30000有效刻生成生殖托。自然静止个体不自动计时、不自动扩散。
- 骨粉60%促成繁殖，人工与已登记自然静止个体均可使用；已带生殖托或异常数据无效。
- 采集沿用采集箱／空袋库存交换接口，包含模拟玩家路径。预扣整格额度，库存拒绝时还原；副作用不明时冻结避免重复交付。成功交付一袋星苔孢子，所有生殖托一起消失；人工株继续下一扩散周期，自然静止株不自动补熟。
- 可选 Jade 显示营养／繁殖状态、扩散／等待繁殖、自然静止、暂停及整格额度。只读已存状态，不推进生长或修复额度。
- 不注册未经确认的培养柜方案；携带未知培养阶段标签的物品不当作普通种植物解释。

`StarMossState` 校验身份、所属结构、阶段、组归属、显式额度、模式及计时。缺失额度不会从模型外观补建。

用户后续确认自然每个16×16区域共4～8格、分1～4小群。已接入共用 `CarpetMossNaturalLayout` 有界规划器，每簇连通、不同簇不相邻、上下落差最多1格，不跨种群区域；地钱仍使用自己的4～10格／1～3簇参数，既有公开入口保留。地钱2,034项布局回归检查、星苔1,864项布局检查均通过。

注册自然 Feature 类型 `life_sanctuary:star_moss_patch`，需要明确提供 `chunk_chance` 和 `reproductive_chance`，无默认猜值。只扫描本区块合法地表并一次规划完整群落，生成失败回退已写入部分，服务器线程延后登记自然静止个体，不在生成线程访问 SavedData。群系标签 `life_sanctuary:star_moss_biomes` 暂为空，尚未添加 configured/placed feature 或 biome modifier，因此当前不会自然生成。

生成频率及初始繁殖比例尚未定案。历史分布清单为中央雨林带、坑壁湿地、裂隙水塘带、碎石坡过渡带，不能仅凭气候适宜扩大自然分布。实际生成和写入失败回退仍需游戏验证。
