# item/ —— 物品图标（32×32）

五个图标由用户用像素工具绘制（原始 144～456 px），裁掉空白后降采样成 **32×32**。

物品贴图尺寸不受限制，选 32×32 是为了保住羽状枝条的细节；
`item/generated` 的模型不需要因为尺寸变化做任何改动。

| 文件 | 内容 |
|---|---|
| `equisetum_arvense.png` | 剪下的营养茎：橄榄绿羽状茎，底部棕色切口 |
| `equisetum_arvense_sprouts.png` | 幼株：同款缩小 |
| `equisetum_arvense_gametophyte.png` | 配子体：**楔叶类共享** |
| `equisetum_arvense_spore_stem.png` | 孢子茎：橄榄细秆 + 琥珀棋盘格孢子叶球 |
| `dead_equisetales.png` | 枯死木贼：灰褐羽状枯茎 |

`item_16/` 里是同一批图标的 16×16 版本，只在需要极简风格时使用。

## 配子体是共享贴图

配子体图标属于**楔叶类（Sphenopsida）全体**，不是问荆专属。
不同物种只是标签（物品名/描述）不同，贴图同一张。
以后做木贼、芦木、楔叶等，不要再各画一份。

如需在资源包里区分，可在 `lang` 里改名称，而不是换图。
