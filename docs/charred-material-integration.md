# 炭化材料引燃与燃尽接入

对应2026-10-27修订第20～22条。CharredMaterialBlock、BurnedMaterialBlock提供可注册的方块方法，CharredMaterialTimers独立SavedData已接服务器活动tick。正式材料、物品和模型未注册，当前不会增加创造栏材料。

## 材料分类

注册炭化材料时提供Properties、CharredMaterialRules.Kind和对应真实燃尽方块ID；燃尽方块使用BurnedMaterialBlock并登记同Kind。FULL用于原木、南瓜、完整纤维块和地下茎等，STEM用于茎。分类明确传入，不根据碰撞是否满格或名字推断，保留孔洞模型的完整材料也可属FULL。

到期会检查真实燃尽方块存在、类和Kind匹配，不能以空气或其他材料悄悄代替。方块沿用原木axis，转燃尽时保留轴向；南瓜雕刻、朝向及特殊形状可由具体材料子类扩展，不能把基础axis实现当作南瓜模型完成。

默认lit=false，天然材料也应初始未燃。已燃FULL亮度14，STEM亮度10，燃尽亮度0；当前使用静态方块模型，无方块实体。原版火蔓延的可燃度为0，避免被原版随机火直接删掉而绕过专用燃尽流程。

## 六面接触与工具

仅六个直接相邻面可提供热源：岩浆块、火标签、熔岩流体、lit=true且Kind=FULL的炭化材料。不查斜角；冷完整块、已燃STEM、燃尽块不能传递本机制。邻居变化和放置时读取至多六格，不扫描世界或全部炭化方块。

未燃材料存在热源后抽一次200～300活动刻，包含两端。普通邻居更新不重抽；已确认六面都无热源时取消，到期再核对热源。多个热源只维护同一个任务，移除其中一个但仍有其他热源不刷新计时。

区块边界读到未加载邻格时不当空气、不强制加载。新对象先进入100活动刻的PROBING，仅探测可用性，不开始引燃；确认热源后才重新开始完整200～300刻。已有合法引燃任务遇到邻格缺失则保留原进度，待可确认后处理。确认无热源即注销。

getToolModifiedState接NeoForge FIRESTARTER_LIGHT与SHOVEL_DOUSE能力，由原版打火石／铲子负责交互、音效和耐久；返回点燃／熄灭后的状态，本方法不改世界、不抽计时。真实状态落地后onPlace同步队列；模拟查询不启动计时。其他模组工具须按其自身流程实际应用返回状态。

## 燃烧到期

沿用原大纲周期：FULL19200～28800活动刻（0.8～1.2日），STEM4800～7200活动刻（0.2～0.3日）。铲熄灭取消燃烧计时，再次点燃重新抽完整时长，不保留已燃进度。持续接触热源的已熄灭块可再经过200～300刻被引燃。

到期只替换为相应燃尽状态，不自动生成骨粉或木炭。邻居通知触发相邻炭化块同步；新点燃完整块才具传火资格，其熄灭或燃尽会通知邻居重新判断。需要骨粉时仍通过破坏／后续配方取得。

队列按基底位置所在活动区块计时，冻结、离线及未活动区块不补算。每维度每tick最多32个到期回调，每区块最多16；缺依赖或暂未成功落地时继承通用100活动刻退避。异常任务保存Failed并停自动重试，防止不确定的世界操作重复执行。

独立存档life_sanctuary_charred_materials版本1保存位置、方块ID、Kind、Phase(PROBING／IGNITION／BURNING)、目标、进度与失败状态；保存时快照活动区块时钟。字段、阶段时长或重复位置不合法时，只读保留原载荷。PlantIndividuals仍为V15，不给装饰炭材创建活体身份。

## 掉落

- 炭化完整块普通固定4木炭，茎固定1，燃烧途中相同；不查时运、不抽数量。
- 炭化材料精准返回本体物品，不带lit或进度组件，重新放置未燃。
- 燃尽材料精准返回其实际燃尽本体物品，普通按原大纲完整块4骨粉、茎1骨粉。
- 燃尽块没有点燃能力或计时，不作为本机制热源。

材料注册时应注意正确工具限制是否会让原版在进入getDrops前拦截掉落，不额外添加旧随机／时运掉落表或重复方块破坏事件。

## 仍需具体接入的内容

正式材料注册、各轴／孔洞／雕刻模型、燃料数据映射、接触伤害和炭堆分段不是本批已完成内容。第23条岩浆湖少量残材仍待生成器配置，不能按本类自动在所有群系生成。世界生成适配可请求该块一次scheduled tick，让服务器主线程初始化；不得在生成工作线程直接写本SavedData。第三方移动若绕过原版放置／移除回调，需要显式迁移或重建位置任务，当前不宣称航空学移动已联调。
