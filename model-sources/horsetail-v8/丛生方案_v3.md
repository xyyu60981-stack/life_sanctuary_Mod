# 问荆「同格丛生」方案 v3

按 10-28 第二轮修订：**排布固定**、**孢子茎找空插**、**同一位置的高矮按株随机**。

---

## 1. 三条规则

### ① 营养茎排布只由根数决定

| 根数 | 摆位 |
|---:|---|
| 1 | 居中 |
| 2 | 对角（-2.6,-2.6）与（2.6,2.6） |
| 3 | 三角（-3.1,-3.1）（3.2,-2.7）（-0.3,3.3） |

孢子茎**不参与**这套排布。

### ② 孢子茎找空插

按根数挑一个空位，不挤占营养茎：

| 根数 | 孢子茎位置 |
|---:|---|
| 1 | (4.2, 4.2) |
| 2 | (2.9, -2.9) |
| 3 | (3.3, 2.9) |

### ③ 同一位置的高矮按株随机

不是"槽0 永远 1.00、槽1 永远 0.90"，而是每种组合准备 **3 套高度组合**：

```
v1: 1.00 / 0.90 / 0.96
v2: 0.92 / 1.00 / 0.88
v3: 0.87 / 0.96 / 1.00
```

方块状态里用**带权变体**随机挑，游戏会按方块坐标稳定取一个 ——
于是同一格、同一状态的两株问荆，长的样子不一样。

### ④ 孢子茎两种材质随机

`fertile_stem`（straw）与 `fertile_stem_rust`（红褐）几何完全相同、只换图集。
同样是带权变体，权重建议 3:1（红褐少一些）。

## 2. 方块状态写法

```json
{"multipart": [
  {"when": {"nutritional_stems": "1", "growing": "false"},
   "apply": [{"model": "life_sanctuary:block/nv1_a1", "weight": 1},
             {"model": "life_sanctuary:block/nv1_a2", "weight": 1},
             {"model": "life_sanctuary:block/nv1_a3", "weight": 1}]},

  {"when": {"spore_stem": "true", "nutritional_stems": "1"},
   "apply": [{"model": "life_sanctuary:block/sp1_straw", "weight": 3},
             {"model": "life_sanctuary:block/sp1_rust",  "weight": 1}]}
]}
```

模型总量：

| 分类 | 数量 |
|---|---:|
| 营养茎组合（3 根数 × 2 生长中 × 3 高度） | 18 |
| 孢子茎（3 位置 × 2 材质） | 6 |
| 合计 | **24** |

比 v2 的 12 个多，但换来了"每株都不一样"。

---

## 3. 元素数

| 组合 | 元素 | 约合面数 |
|---|---:|---:|
| 1 根 + 孢子茎 | 105 | ~230 |
| 2 根 + 孢子茎 | 178 | ~390 |
| 3 根 + 孢子茎 | **251** | ~550 |

这是这个方案最大的成本。三个缓解办法照旧：轮生枝 8 片/圈减到 4 片（砍半）、
只在 3 根时简化、或者先上再测帧数。

## 4. 仍然要处理的连带问题

1. **动辄超过一格**：有成年株时高 23.2，需要 `lower/upper` 拆分（工具已有：
   `tools/split_two_block.py`，跑一遍即可）。只含幼株/孢子茎时只占一格。
2. **`growing` 属性**：代码里目前没有，需要加到 `EquisetumArvenseBlock`。
3. **`spore_stem` 与孢子茎材质**：随机材质走方块状态权重即可，不需要存档字段。
