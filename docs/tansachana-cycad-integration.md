# 坦萨苏铁基础接口

第38条登记`life_sanctuary:cycas_tansachana`共享物种，学名按用户给定Cycas tansachana。复用CycadGrowthProfile成长图、种群和空间门槛，不复制一套世界tick。当前是正式物种适配前的元数据和规划／校验接口，尚未注册植株方块、物品、模型或自然生成。

## 差异参数

- 成年高度15～20格，深绿色语义叶色板；具体RGB和叶片模型由内容作者提供。
- 成年要求2～3次分支。requiredBranches=true使permitsShape拒绝0／1次和超过3次；普通苏铁仍保留“高于5格可以分支”的可选语义，不因本条变为强制分叉。
- 自然种群2～3株、不含OFFSHOOT，区域沿统一苏铁为32×32，上限3。
- 亚成到成年15～20天，即360000～480000活动tick；种子1～3天、小苗2～4天、重种侧芽1～3天沿天窗苏铁。天然侧芽仍需静止来源，不因转换定义而自动长大。
- 骨粉沿天窗苏铁无效。主干、侧芽、开花／种子具体方块尚未注册，元数据不等于实际骨粉交互已经联调。

已提供`life_sanctuary:cycas_tansachana_biomes`标签，当前仅minecraft:badlands，不自行扩大至风蚀／疏林恶地；正式群系表可调整。没有激活生成频率或BiomeModifier。

## 粗主干XYZ接口

TansachanaCycad.trunkPositions以个体基底为底层中心，X/Z各±1，Y从基底向上：height=3为3×3×3的27格，height=4为3×4×3的36格。拒绝其他高度并检查整数坐标溢出；不把3×4×3误写成3×3×4，也不把角落当个体基底。

TansachanaCycad.hasTrunk检查ADULT目标结构中主干专用role完整覆盖这些格子，且该role没有额外溢出格。侧枝需用不同role。此检查不读取世界，不是世界放置器；正式适配器仍需构建完整PlantStageStructure、记录全部世界依赖，并通过现有阶段／结构事务提交。仅验证主干覆盖，不能代替整株15～20格形态、实际主干材质／碰撞体或叶冠合法性。

27／36格是同一个体的部件，不能各建独立UUID或各占种群名额。仍按中心基底判断区块和种群归属；结构跨边界不拆个体。主干3／4格是主干模块尺寸，整株15～20格包括其余分支及叶冠，不把两个高度值混作同一参数。

## 自然种群的雌雄保证

CycadNaturalSexes.sampleTansachana只接受2／3个主株，先形成性别方案，ensureBoth检查至少一雌一雄；全同一性别才随机翻转一株，已混合的方案保持不变，输入列表不被修改，输出不可变。这个纠正也可用于基线苏铁活动成年株的预选结果，但不在本批擅自触发或重新选择活动母株。

Sex.FEMALE／MALE是自然种群方案的性别，**不是PlantFlowerState的花性别，也不是新增的世界性别存档**。正式生成器必须把方案和实际个体一一绑定，随其方块／个体状态保存，不应重进、重载或空间失败后重抽；当前尚无实际生成器调用它。因此已提供雌雄保证算法，不声称现有世界已生成有雌雄标签的坦萨苏铁。

## 继承接口与尚待接入

沿用PlantGrowthSpace的幼苗3×1×3和亚成3×2×3额外检查，再由完整目标事务检查全部粗主干／分支／叶冠空间。更高阶段邻株竞争、侧芽排除、母株活动和支撑逻辑仍由苏铁物种适配提供。

开花窗口、三次2000刻搜雄、第三次21×5×21及+20个百分点由已有PlantCycadRules／PlantNaturalPollination提供。尚未确定的产种上下限、供粉资格和种子物品必须显式接入，不从旧果锥数量猜测。种皮可接第34条同物品外观接口。

## 验证边界

全源码以本地缓存依赖独立javac通过，未运行Gradle。临时检查覆盖长成熟期及其他继承时段、32×32／3上限、15～20高度及2～3分支采样、强制分枝与普通苏铁可选分枝回归、所有2／3成员初始性别组合的最少修改保证、27／36格居中XYZ坐标和无侧芽计数。

未启动游戏，未验证真实三维主干、阶段成长、自然种群、性别持久化、供粉／结种或美术。这些需正式物种／生成适配后联调；本批不等于坦萨苏铁已完整可游玩。
