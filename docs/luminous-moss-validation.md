# 光藓验证与剩余接入

## 本批实现（2026-10-29）

### 自然生成最终参数（用户已确认）

平均每4个符合条件的区块尝试一个种群，成功时2～4格，初始每株独立25%概率带孢蒴，不强制每群至少出现一个cross。已接configured_feature→placed_feature→NeoForge add_features biome modifier；仅luminous_moss_biomes标签中的坑壁湿地参与。群系本体未注册时该可选标签为空，不会回退在原版群系生成。

参数位于worldgen/configured_feature/luminous_moss_patch.json的config：chunk_chance=4、capsule_chance=0.25，可通过数据包覆盖。概率门控只在Feature执行一次，placed_feature不再额外叠加rarity_filter；chunk_chance表示平均尝试间隔，不保证固定每4区块恰好有一群。空间不足或基底不合法时此次不生成。

Configuration使用范围校验Codec，兼容旧空config并采用已确认的默认值，拒绝非法间隔、概率及非有限数。自然孢蒴在延后的静止个体登记中获得1次额度；采后没有自动再生计时。配置不追溯改写已经生成的植株或旧区块。

已对照本地NeoForge AddFeaturesBiomeModifier源码核对JSON字段，独立javac与315项配置／Codec／边界概率检查通过；真实新区块、地形与光照传播仍待游戏验证。

### 培养柜衔接（后续批次）

光藓注册单段ADULT培育方案，沿用确认后的自然成长48000～72000刻、机器60%（28800～43200刻，即1.2～1.8游戏日）及一袋四份规则。没有凭空增加孢子瞬间萌发的耗时阶段；本方案只提供完成后的成年产物，不在未完成时伪造可领取幼苗。

真实产物使用已有lichen_photobiont物品，写入通用已完成阶段组件，不保存柜内未完成进度。物品适配校验真实物品、物种、ADULT阶段和已注册的阶段产物模板；带有未知／损坏阶段记录时拒绝放置，不回落普通幼苗。普通光藓物品仍从幼苗开始。

培育成株通过同一出生结构事务放置为AGE=1、ADULT、ONE_TIME及ONE_TIME_CULTIVATION来源，起始孢蒴额度0，不启动成年自动扩散周期。世界位置、种群4格上限、基底、气候缓存与失败不消耗路径共用；不把已完成成株降成幼苗或重新抽2～3日时长。物品提示区分普通种植／成年培育产物／无效记录。

完整独立javac通过；新增810项纯配方／时序／输出阶段及存档检查通过，包括60%时长范围、断电不推进、差一刻不得领取、四份最终产物、无下一阶段重复乘四、失败批次不发物、错误物种／阶段拒绝。真实培养柜库存交付、标记物品放置、漏斗提取与多人联调仍未进行游戏测试。

## 本机独立检查

后续保存边界补充：LuminousMossState纯校验统一核对物种／基底种群、唯一部件归属、外观阶段、孢蒴额度、扩散／孢蒴等待模式和对应时长。只缺旧气候缓存时保持UNKNOWN，首次实际成长回调补一次检测；额度缺失、外观与额度冲突、错误计时等不自动修复或重置额度，活动回调标记moss_state_error并暂停，避免100刻无限重试。Jade只读提示同一结果，不在悬停时补缓存。

管理员可用`/life_sanctuary moss inspect <x> <y> <z>`只读查看UUID、种群、来源、阶段／实际外观、剩余刻数、额度、等待模式、干燥缓存、一致性与暂停原因。未加载区块拒绝，不强制加载，不更新环境或修复数据。即便实际方块已不在，仍可查询该基底残留的已登记光藓记录，外观值-1用于诊断。

新增135项针对阶段／额度／周期范围／种群／缺缓存／自然静止／一次性来源及只读性的纯一致性检查通过。未以这些检查代替真实服务器保存或人为损坏存档的恢复测试。

完整源码含新类与Jade适配通过独立javac，无弃用警告。188份资源JSON可解析。临时规则检查覆盖额度预扣／精确恢复、不覆盖其他资源、阶段转换保留身份／部件／种群名额、全阶段与来源合计、保存重载后的计时／模式／额度、寒冷和故障门控、负坐标16格分区与自然2～4数量，合计5458项断言通过。临时检查位于被忽略的build目录，不是正式游戏测试套件。

## 游戏验证清单

1. 普通光藓及满光藓孢子袋种于泥土、石头、苔藓、原木、石砖、圆石；半砖等不完整上表面拒绝。腐朽／炭化材料完成注册后须加入对应标签。
2. 同区放4个、混合不同阶段，第5个拒绝；破坏一个释放名额，幼苗成年不占第二个名额。负坐标和16格边界分别计数。
3. 幼苗保存重进及区块卸载／重载保留进度，不因睡眠或改时间直接成年。寒冷出生不成长，炎热正常；干燥允许本阶段成熟但不扩散。
4. 成年活动株骨粉60%生成cross；已有孢蒴和寒冷株骨粉不消耗。模型／亮度变为孢蒴态14。
5. 手持或装备采集箱装有空袋，得到一袋带光藓标签的孢子并回成年亮度7。无袋、名单拒绝、满箱无可用交换位置时外形／额度不变；最后一个空袋腾位置仍能交换。
6. 机械手手持空孢子袋按原库存路径输出；本批没有新增Create Mixin，仍需实际自动化联调。
7. 正常扩散只产生一个幼苗且不跨种群边界；满群／阻挡后进入已保存的孢蒴等待阶段，途中保存重进不重抽时间。
8. Jade看幼苗、成年、孢蒴、静止和故障状态；切换目标不串数据。不装Jade时客户端及专用服务器均可启动。
9. 剪刀／精准掉普通物品，不携带孢蒴额度；普通破坏、失去基底及活塞无本体掉落，清理身份。大面积种植的实际帧率与到期尖峰需测量。
