# 泥炭与植物接口

## 已确认规则

- 泥炭具有泥土标签，可被苔藓转化；泥炭耕地是另一种方块，不默认享有植物泥炭奖励。
- 泥炭燃料使用NeoForge炉燃料数据映射，默认16000 tick，与当前版本煤炭块相同；普通熔炉连续冶炼可完成80个每件200 tick的配方。数据包可覆盖本值，不需要每tick执行额外逻辑。
- 合法生长在泥炭上的孢子植物，每个成熟可采集结构额外1次采集额度。
- 问荆适用通则：普通基底1次，泥炭2次；采完后保留外形，不补额度。
- 种子植物每次在原随机产量之外加1粒种子，不增加采集次数，不重新抽取基础产量。
- 不增加生长速度，不按多个基底重复叠加。奖励在成熟轮次初始化时保存，不能通过移走、补回泥炭或重载刷新。

## 接口

PeatResponsivePlant声明奖励类型并判断是否接触合法泥炭。默认只检查下方基底及存活条件；多基底或连通植物覆盖hasEligiblePeat，返回一个布尔结果，不累计基底数量。

PeatPlantInteraction.capture捕获本轮奖励类型；initialHarvests与seedYield分别处理孢子采集次数和种子产量。调用方必须保存捕获结果，不得在每次采集时重新计算。

问荆记录保存在HorsetailPopulations，SporeHarvests中的Remaining为剩余次数，PeatBonus为本轮奖励记录。零额度必须保留，防止再次初始化。旧存档既有额度不追溯加成。

## 后续接入边界

翠云草、小翠云的全株传播、库克逊蕨分叉奖励是独立规则，尚未接入。
问荆生成孢子茎的流程必须在结构成熟时调用initializeSporeStem(level, pos)；不能只依赖同种方块属性更新时的onPlace。
破坏后携带成熟额度的物品数据、重种继承、实际种子掉落入口尚未完成；当前按位置保存不能单独保证物品搬运后的额度继承。
泥炭耕地已加入翻耕、原版润湿和空地干燥退化逻辑，所有退化路径返回泥炭。踩踏要求落距至少3格，并尊重NeoForge踩踏事件和生物破坏规则。普通挖掘掉泥炭，精准采集掉耕地。允许作物及瓜茎种植，拒绝本Mod植物，未加入泥土或泥炭奖励标签。暂用原版耕地顶面与泥炭侧面。
成熟小麦、胡萝卜、马铃薯和甜菜已接入方块掉落事件增产：只对实际掉落的主要产物额外加30%，不足1件的部分按概率取整，长期平均增加30%。例如1个小麦有30%概率额外掉1个。保留时运等已经产生的基础结果，种子副产物、毒马铃薯、西瓜、南瓜及未成熟作物不加成。胡萝卜、马铃薯本身既是产物又可种植，作为主要产物享受加成。
只覆盖实际触发BlockDropsEvent的收获路径；绕过该事件的右键采收、其他模组机器和作物需单独适配，当前不承诺兼容。无持续tick扫描，不增加生长速度。
草杆捆转化及世界生成仍为后续工作。

## 本地游戏验证

1. 将泥炭放入普通熔炉燃料槽，使用持续供应的普通冶炼配方，确认可作为燃料且与煤炭块时长一致。
2. 确认普通基底、泥炭上的新成熟可育结构分别初始化为1次、2次；采完、存档重进后额度仍为0。
3. 已初始化结构移走再补回泥炭，确认不会再次增加额度。
