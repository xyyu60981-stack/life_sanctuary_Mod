# 腐朽空心原木与虫卵

对应2026-10-27修订第15条。RottenHollowLogBlock提供方块方法与含水适配，HollowLogEggSoaking已接服务器活动tick。正式原木与通用草杆尚未注册；当前没有新增可见物品，也没有用问荆物品替代通用草杆。

## 注册与模型

注册正式方块时构造RottenHollowLogBlock(Properties, Item stalk)，传入真实通用草杆物品；不能传空气。CODEC保存草杆注册ID。方块物品使用普通BlockItem，需保证原版玩家破坏流程能进入自定义掉落，避免额外requiresCorrectToolForDrops标志提前拦截。

方块有axis、eggs、waterlogged状态，沿用原木轴向。物种作者为有卵模型在空心内部绘制3个白色虫卵、每个3～4像素，不使用实体或动画显示。空心碰撞／选框、纹理变体、音效及硬度仍由材料与模型适配。普通物品放置总为无卵；自然生成入口明确给出eggs初始状态，不在加载、邻居更新或掉落查询时重抽。原大纲20～30%有卵比例由后续世界生成配置决定。

## 破坏与回收

- 普通破坏返回2～4个草杆，不因时运增加。
- 精准采集返回1个本体物品，不写入活卵或方块状态组件，重新放置仅作无卵装饰。
- 仅有卵、非精准且doTileDrops开启时，在spawnAfterBreak生成原大纲规定的1～3蠹虫；清卵后不再生成。

实体生成与getDrops分离，掉落预览或重复计算掉落列表不会生成蠹虫。不要另外添加事件回调再生一次蠹虫。创造破坏和爆炸沿用原版是否调用实际掉落流程的行为，正式接入后需游戏确认。

## 含水清卵

实现SimpleWaterloggedBlock，放水／取水通过原版接口处理，邻居变化安排原版流体tick。有卵且含水时，在该维度独立SavedData登记一个200～300活动tick的任务，含两端；重复同步不重抽。完成仅把eggs变为false，保留axis、水状态和其他属性，并正常通知邻居。

移水取消当前任务，重新含水重新计时。移除方块注销原任务；到期再核对位置实际方块类型及含水／虫卵状态，不强制加载区块。活塞或其他系统搬移时，原位置移除、新位置放置分别取消／初始化；若第三方移动绕过原版回调，需其适配器同步位置，当前不宣称航空学移动已联调。

无方块实体和逐原木ticker。队列仅遍历有任务的活动区块，并按到期预算执行；未活动区块、服务器冻结、离线时间不计入进度。运行时按区块时钟累计，保存时快照实际进度。异常任务保存Failed并停止自动重试，避免重复执行不确定的世界修改；普通重复同步不抹掉失败历史，移水／移除结束此周期。

独立存档life_sanctuary_hollow_log_eggs版本1保存Position、Block、Target、Elapsed、Failed，不改PlantIndividuals V15。字段缺失、计时越界、重复位置或未知版本只读保留原载荷，不能通过重载刷新计时。Failed不重新加入队列。
